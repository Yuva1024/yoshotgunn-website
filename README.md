# W ONES — studio site and Yo! ShotGunn

Static website for the W ONES game studio and its first game, **Yo! ShotGunn**.

- `index.html`: the studio site (`studio.css`, `studio.js`)
- `yoshotgunn.html`: the game page (`styles.css`, `script.js`)
- `assets/`: images (WebP), footage clips, fonts, and character art

No build step. Open `index.html`, or serve the folder with any static server:

```
python -m http.server 8777
```
